Fuzzy Logic: Fan Speed Controller

Mamdani fuzzy inference, the same as your Python code. Move the sliders and every stage updates live.

Crisp inputs → 1. Fuzzification → 2. Rule evaluation → 3. Clipping & aggregation → 4. Defuzzification (centroid) → Crisp fan speed

Inputs

1Fuzzification

Each crisp input is turned into membership degrees (0 to 1) for every fuzzy set. The dashed line is the input value; each dot is where it crosses a set.

Temperature: cold = tri(0,0,20), warm = tri(10,20,30), hot = tri(20,40,40)
Humidity: low = tri(0,0,60), high = tri(40,100,100)

2Rule evaluation

AND = min, OR = max. Each rule's result is its firing strength: how strongly its output set is activated.

3Clipping & aggregation, then 4Defuzzification

Each output set is clipped (cut off) at its rule's firing strength: min(R, set(i)). The clipped shapes are combined with max into one aggregated shape. The centroid (centre of gravity) of that shape is the crisp fan speed.

Fan speed (0–100): slow = tri(0,0,50), medium = tri(25,50,75), fast = tri(50,100,100)
